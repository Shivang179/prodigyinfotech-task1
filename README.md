# Population Data Analysis

## About the Project

This project was completed as part of my Data Science Internship at Prodigy InfoTech.

The main objective of this project is to analyze world population data using Python. I performed data cleaning, explored the dataset, and created different visualizations to better understand population trends across different countries.

---

## Dataset Used

The project uses the following datasets:

- worldpopulation.csv
- API_SP.POP.TOTL_DS2_en_csv_v2_33112.csv
- Metadata_Indicator_API_SP.POP.TOTL_DS2_en_csv_v2_33112.csv

---

## Tools & Libraries

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib

## What I Did

- Loaded the population dataset
- Cleaned the data
- Explored different population statistics

- Analyzed the results and observed population trends
